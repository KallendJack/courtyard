# fresh-start

What a fresh start would clear, and starting one. The worker's side is
[`fresh-start/`](../../../../worker/src/features/fresh-start/README.md).

**Example:** Fresh start lists the workspaces it would clear and the sessions it would set aside; you confirm, and
Courtyard starts clean.

- **Uses:** `api/worker.ts`.
- **Used by:** the Fresh start page (`routes/_app/fresh-start.tsx`).

## Screens

- Its page is in `routes/`; this folder has its calls (`api.ts`).
