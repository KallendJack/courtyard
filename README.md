# Paper boards for cloud sessions

Agreed boards (Paper page **2 · Agreed**) exported as images, one folder per issue, for builders that can't reach the Paper connection (Claude Code cloud sessions). Paper stays the source of truth; this branch is a read-only snapshot.

Use it from your issue branch without checking it out:

    git fetch origin paper-boards
    git show origin/paper-boards:186/component-update-when-ready.png > /tmp/board.png

Compare your own Playwright screenshots (950×712 unfolded Fold, 400×900 cover, 1440×900 desktop) with these. The boards are drawings: build with the theme's names and shared components (AGENTS.md), not pixel values read off an image. Where a board and the issue's grill decisions disagree, the decisions win; say so in the PR.

Snapshot: 2026-10-15. Re-exported by the local session when boards change.
