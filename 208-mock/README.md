# Planning Home mock (2026-10-15): to draw in Paper

These aren't exported boards. They're the **mock agreed with the owner in a cloud session**, which had no Paper connection, for the local session to redraw on Paper's **3 · Drafts** page. The owner then finalizes them in Paper and moves them to **2 · Agreed**; only then are #208's screens built.

Each `.dc.html` file is one board: plain HTML and inline styles in Courtyard's Handheld theme. Ignore the `<x-dc>` wrapper and the `support.js` line, which belong to the claude.ai canvas the mock was drawn in. `canvas.json` gives each board's size and title, and the owner's notes.
